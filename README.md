# Movie Ticket Booking System (Java)

## Description
This is a console-based Movie Ticket Booking System developed using Java. 
It allows users to select movies, choose show timings, book seats, 
and confirm payment.

##  Technologies Used
- Java

##  Features
- Movie selection
- Show timings display
- Seat booking
- Amount calculation
- Payment confirmation

##  How to Run
1. Compile:
   javac Main.java
2. Run:
   java Main

##  Project Structure
- Main.java

## Sample Output
User selects movie → enters seats → gets total → confirms booking
