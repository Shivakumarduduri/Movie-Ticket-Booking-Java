# Movie Ticket Booking System (Java)

## Description
This is a console-based Movie Ticket Booking System developed using Java. 
It allows users to select movies, choose show timings, book seats, 
calculate total amount, and confirm booking through a simple interface.

##  Technologies Used
- Java

##  Features
- Display available movies
- Show different time slots
- Seat booking system
- Automatic amount calculation
- Payment confirmation

##  How to Run
1. Compile the program:
   javac Main.java
2. Run the program:
   java Main
3. Follow the instructions displayed on the console

##  Project Structure
- Main.java

## Sample Output
User selects movie → enters seats → gets total → confirms booking
